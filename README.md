# CODE QUEST

> من فريق **حلول كود — Halul Code** · تصميم وتطوير: **المهندس مهند القدسي**

لعبة ويب تفاعلية احترافية لتعلّم **المصطلحات البرمجية بالإنجليزية**، مبنية بالكامل من ملف
`Programming_Glossary_En_Ar.xlsx` — بلا مصطلحات مكتوبة يدويًا وبلا اعتماديات خارجية.

> An interactive, premium web game for learning English programming terminology.
> Everything is generated from the Excel glossary; the runtime has **zero npm dependencies**.

---

## 1. التشغيل السريع / Quick start

```bash
# Node.js >= 22.5 (يستخدم node:sqlite المدمج)
npm start
```

- اللعبة: <http://127.0.0.1:5173>
- لوحة الإدارة: <http://127.0.0.1:5173/admin>
- حساب الأدمن الافتراضي: `admin` / `CodeQuest!2026`
  (يمكن تغييره عبر `ADMIN_PASSWORD` **قبل أول بناء** لقاعدة البيانات)

لا توجد خطوة build ولا `npm install`. الواجهة Vanilla JS/CSS مع ES Modules وHash Router.

### إعادة بناء قاعدة البيانات من Excel

```bash
npm run seed -- --force
```

| متغير البيئة | الافتراضي | الوظيفة |
| --- | --- | --- |
| `PORT` | `5173` | منفذ الخادم |
| `HOST` | `0.0.0.0` | عنوان الاستماع (Render/PaaS) |
| `CODEQUEST_DB` | `data/codequest.db` | مسار قاعدة SQLite |
| `CODEQUEST_SOURCE` | `data/source/Programming_Glossary_En_Ar.xlsx` | ملف Excel المصدر |
| `ADMIN_PASSWORD` | `CodeQuest!2026` | كلمة مرور الأدمن عند البناء |

> `--force` يمسح الجداول ويعيد الاستيراد. بدونه يتوقف السكربت إذا كانت القاعدة تحتوي مصطلحات.

## 2. الاختبار / Tests

```bash
npm test
```

يشغّل الاختبار بيئة معزولة تمامًا:

1. يبني `data/test-runtime.db` من ملف Excel الأصلي.
2. يشغّل الخادم على منفذ عشوائي.
3. يفحص الواجهة، المصادقة، المحتوى، الأنماط الثمانية، العزل بين اللاعبين، الملف الشخصي،

   الاستيراد/التصدير، وسلامة البيانات.
4. يحذف قاعدة الاختبار في النهاية (أو يبقيها مع `CQ_TEST_KEEP=1`).

**النتيجة الحالية: 529 فحصًا ناجحًا، 0 فاشل.**

## 3. المزايا

### اللعب
- **8 أنماط**: خمّن المعنى، تحدي الإنجليزية، طابق المصطلحات، لغز الكلمات، أكمل الشيفرة،
  تحدي السرعة، معركة الزعيم التقني، مصطلحات متشابهة.
- **15 عالمًا** تغطي **50 تخصصًا** و**50 مرحلة** متسلسلة مع شروط مستوى وفتح تدريجي.
- **9 رتب**، مستويات، XP، عملات تُصرف على عناصر تجميلية فقط (لا شراء إجابات).
- **6 زعماء** و**12 إنجازًا** و**8 منافسين NPC** في لوحة الصدارة.

### التعلّم
- **مراجعة ذكية** (Spaced Repetition) مع قائمة مستحقة وتحديث الفواصل حسب الإجابات،
  وعدّاد الشارة يعرض فقط المصطلحات التي لها سؤال فعلي قابل للمراجعة.
- **قاموس تفاعلي** ببحث وفلاتر (تخصص، صعوبة، حالة التعلّم، حالة الترجمة، المفضلة)،
  نطق عبر `speechSynthesis`، ومصطلحات ذات صلة وأمثلة.
- **تحدي يومي** وكلمة اليوم وإحصاءات ورسوم 14 يومًا وتقدم حسب التخصص.

### الاشتراكات واللعب الجماعي
- **تجربة مجانية**: 10 إجابات يوميًا لكل حساب جديد، ثم يلزم اشتراك لإكمال اللعب
  (كل الأنماط، التحدي اليومي، المراجعة، واللعب الجماعي).
- **خطتان**: شهري **100 ريال / 30 يومًا** وسنوي **1000 ريال / 365 يومًا**.
- **تحصيل يدوي**: يرسل اللاعب طلب تفعيل مع مرجع التحويل، ويراجعه الأدمن من تبويب
  «الاشتراكات» (موافقة/رفض/منح مباشر). التجديد يُمدَّد من نهاية الاشتراك الحالي.
- **لعب جماعي 1 ضد 1**: غرفة بكود دعوة من 6 أحرف، نفس 8 أسئلة للطرفين، نقاط
  تُحتسب على الخادم، مؤقت 180 ثانية، ونتيجة ومكافآت XP/عملات تُمنح مرة واحدة.
- الأدمن مشترك دائمًا ولا يظهر له شريط التجربة.

### الواجهة
- عربي/إنجليزي مع **RTL/LTR**، وضع داكن/فاتح، تصميم Glassmorphism/Neon متجاوب.
- مؤثرات صوتية مولّدة عبر WebAudio (بلا ملفات صوت) ويمكن إيقافها.
- معالجة أخطاء واضحة، حالات فراغ، واستئناف جلسات اللعب عبر `#/play/:sessionId`.

## 4. البيانات / Data policy

- **المصدر الوحيد**: ورقة `Programming_Glossary` في ملف Excel. لا تُكتب مصطلحات يدويًا.
- 1000 مصطلح / 50 تخصصًا / 20 مصطلحًا لكل تخصص تقريبًا.
- **210 ترجمة عربية موثقة** → `translation_status='verified'` وتُستخدم في أسئلة المعنى والإنجليزية.
- **790 ترجمة Placeholder** → `needs_review`؛ لا تُولّد لها أسئلة معنى، وتُعرض في القاموس مع
  شارة «قيد المراجعة»، ويُستخدم التعريف البديل في ألغاز الكلمات حتى تُراجع.
- **لا استخدام لـ `Game_Data`** في أي منطق لعب؛ الاختبار يضمن ذلك.
- المشتتات (الخيارات الخاطئة) تُولّد من نفس التخصص عند توفر 3 مرشحين، وإلا من كل المصطلحات،
  مع **إجابة صحيحة واحدة مضمونة** لكل سؤال.
- الاستيراد يطابق المصطلحات بـ `english_key` (بلا تكرار)، ويدعم **Dry Run** لا يعدّل القاعدة،
  ويعيد توليد أسئلة المصطلح بأمان (تعطيل القديم بدل حذفه للحفاظ على سجل اللاعبين).
- التصدير يعيد المصطلحات والأسئلة بصيغة XLSX قابلة لإعادة الاستيراد (دورة كاملة).

## 5. الأمان

- كلمات المرور بـ `scrypt` + ملح عشوائي.
- جلسات `HttpOnly` + `SameSite=Lax` مع رمز **CSRF** لكل الطلبات المتغيّرة.
- حماية لوحة الإدارة بدور `admin` مع منع تعديل حساب المدير من نفسه.
- استعلامات SQL معلمّية (Parameterized) وForeign Keys وWAL.
- **الخادم لا يرسل الإجابة الصحيحة** ولا حقول المصطلح التي تكشفها قبل الإجابة؛
  تُعاد الإجابة والشرح فقط بعد التصحيح.

## 8. النشر على Render / Deploying

الخادم مرتبط من الصندوق مع أي PaaS يدعم Node سواء `HOST=0.0.0.0` أو منفذ من البيئة.

**عروض Render المجانية تفقد البيانات المؤقتة عند كل إعادة نشر — لن يُنصح بلعبة متعددة اللاعبين عليها.**
للنسخة الإنتاجية المطلوبة لهذه اللعبة:

1. **ربط المستودع**: أنشئ Web Service في Render مرتبطًا بمستودع `mohnadalqdasy02026/halul-codequest` (خاص).
2. **Runtime**: `Node` · **Build Command**: `npm install` (لا توجد اعتماديات) · **Start Command**: `npm start`.
3. **قرص ثابت (Persistent Disk)**: أضفه mount path `/var/data` وحجم **1 GB** (مدفوع).
4. **Environment Variables**:
   - `CODEQUEST_DB=/var/data/codequest.db` — مكان القاعدة على القرص الثابت.
   - `ADMIN_PASSWORD=<كلمة سر قوية>` — تُستخدم فقط عند البناء الأول للقاعدة.
   - `HOST=0.0.0.0` (الافتراضي).
   - `PORT` يُحقنه Render تلقائيًا.
5. عند أول تشغيل يبني `scripts/ensure-db.js` القاعدة من ملف Excel تلقائيًا.
6. تحقق من: `https://<your-service>.onrender.com` ثم `/admin` بحساب المدير.
